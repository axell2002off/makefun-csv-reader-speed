A fast drop-in replacement for csv-reader 1.0.0: a single-pass, slice-based parser in solve.js that returns exactly the reference reader's {columns, rows, errors} on every input — including broken rows, stray CRs, quoted fields and unterminated quotes — at roughly 7-9x lower CPU time on the practice set.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
